# 昔言语录

在 ClassIsland 主界面显示随机语录，支持按分类筛选和定时更换。

## 数据与离线使用

插件始终从本地存档抽取语录，不依赖在线随机接口。安装包附带一份语录库；ClassIsland 启动后会后台尝试同步，失败时继续使用已有本地数据。也可以在组件设置中点击“立即同步”。

语录格式与服务来自 [CyQuote 昔言](https://github.com/Cyrene2008/CyQuote)，完整数据集同步自 [CyTime](https://github.com/Cyrene2008/CyTime) 的 `api/data/quotes.jsonc`。
