# 昔言语录

在 ClassIsland 主界面显示随机语录，支持按分类筛选和定时更换。

## 自适应排版

语录与作者、出处合并为一个字段展示，组件按有效宽度上限（窗口宽、或组件高级设置里的固定/最大宽度）自动决定排法：

- 单行放得下：保持主题原字号，一行显示；
- 单行放不下：在“最小字号 ~ 原字号”里选一个既排得进最大行数、又不超可用高度的最大字号（默认 45px，对应 ClassIsland 行高 40 + 行距 5），既不浪费屏幕也不压到下一行；
- 两行还放不下：在署名之前断句并加省略号，断点回退到最近的句读之后——署名永远不会被截断。

相关设置：自适应排版开关、最大行数、最小字号、可用高度。“单行显示”仍可强制单行，超出部分以省略号收住，不再超出屏幕。

## 数据与离线使用

插件始终从本地存档抽取语录，不依赖在线随机接口。安装包附带一份语录库；ClassIsland 启动后会后台尝试同步，失败时继续使用已有本地数据。也可以在组件设置中点击“立即同步”。

语录格式与服务来自 [CyQuote 昔言](https://github.com/Cyrene2008/CyQuote)，完整数据集同步自 [CyTime](https://github.com/Cyrene2008/CyTime) 的 `api/data/quotes.jsonc`。
